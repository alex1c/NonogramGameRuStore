Политика конфиденциальности

Приложение «Японские кроссворды — Нонограммы» · пакет com.calculatorplatform.nonogram

Разработчик: ForestMusic · forest-music.ru

Какие данные хранятся локально

Прогресс кампании, галерея, кроссворд дня, статистика, достижения, состояние активного уровня и факт прохождения обучения хранятся на устройстве пользователя. Приложение не требует аккаунта и не собирает профиль пользователя (имя, e-mail и т.п.).

Аналитика

Приложение использует Яндекс AppMetrica для событий использования (например: открытие приложения, старт/завершение партии, Daily, обучение, подсказки, открытия галереи/достижений). В аналитику не передаются решение кроссворда, состояние доски игрока, свободный текст и персональные данные.

Реклама

Приложение использует Яндекс Mobile Ads (РСЯ) для показа рекламных блоков: баннеры на подходящих экранах, редкая межстраничная реклама после просмотра результата решения и (в будущем) добровольная вознаграждённая реклама. Обучение не содержит рекламы. Сбой загрузки рекламы не блокирует игру.

Offline

Основной игровой процесс (уровни, Daily, галерея, подсказки, сохранения) работает без сети. Недоступность аналитики или рекламы не мешает игре.
